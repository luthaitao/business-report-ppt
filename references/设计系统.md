# 商务汇报 PPT 设计系统(从 91 套模板蒸馏)

> 本文所有规律来自对 91 套模板的实测:缩略图 6 色量化、形状填充色直方图、字体/字号直方图、页面文本结构分析。
> 用途:① 选风格族时对照配色与字体;② 无合适模板时按本系统从零搭页面;③ 校验生成结果是否"像这套库里的东西"。

## 1. 画布与网格

| 项目 | 实测值 | 说明 |
|---|---|---|
| 页面尺寸 | 33.9 × 19.1 cm(13.33 × 7.5 in,16:9)为绝对主流 | 91 套中 86 套;仅 023/051/061/074 为 4:3(10 × 5.62 in),079 为 10 × 7.5 in |
| 页标题位 | 左上 x≈0.8 cm、y≈1.2 cm,字号 28–36 pt | 标题下常跟一条细分隔线或 `>>>` 装饰 |
| 内容主体区 | y≈3 – 16 cm | 占页面约 70% 高度 |
| 右上角 | x≈29–31 cm、y≈0.5 cm | **模板 logo 位(组合形状,构建时 drop 掉)** |
| 底部 | y≈17–18 cm | 色带/页脚装饰,内容不压底 |
| 一页一边缘 | 左右留白 ≥0.8 cm | 投影仪安全区,文字不贴边 |

## 2. 字体规范(实测频次)

- **中文首选:微软雅黑**。23 个可解析模板中 13 个以它为主字体(单套出现 99–755 次),是这套库的"默认普通话"。
- 可选风格化字体(按模板):方正兰亭系(纤黑/中粗黑/超细黑)、方正大黑、华文细黑、张海山锐谐体、华康俪金黑——**仅在同族模板已使用时选用,不跨族混搭**。
- **西文/数字**:Arial、Calibri、Franklin Gothic、Impact、Helvetica、Century Gothic;数字大字常用 Impact/Franklin Gothic Heavy 做视觉锤。
- **不用的**:宋体做标题(仅 080 等旧模板用)、艺术字特效、超过 2 种中文字体。

### 字号阶梯(全库实测聚合)

| 层级 | 字号 | 典型用途 |
|---|---|---|
| 封面主标 | 66–115 pt | 4–6 个汉字或 8–12 个拉丁字符;超出即裁切,宁短勿长 |
| 封面副标 / 章节号 | 40–60 pt | 副标题、过渡页大编号 |
| 页标题 | 28–36 pt | 内容页左上角标题 |
| 卡片/条目标题 | 20–24 pt | 目录条目、卡片头、图表标签 |
| 正文 | 12–16 pt | **投影可读下限 12 pt;14–16 pt 最稳** |
| 注释/来源 | 9–11 pt | 口径说明、英文装饰小字 |

## 3. 配色纪律

### 3.1 60-30-10 法则(本库所有模板都符合)

- **60% 中性基底**:白/浅灰(#FFFFFF–#E6E6E6,浅色模板)或近黑(#0B0B0B–#262626,深色模板);
- **30% 辅助色**:同族邻近色(深一档的主色或灰蓝);
- **10% 强调色**:每页只用一个强调点(一个红色块、一组数字、一个高亮卡片),**一页至多一个强调色**。

### 3.3 数据呈现约定(中国商务惯例)

- **业绩/股价类:涨 = 红,跌 = 绿**(本库红黑/红系模板的默认语义,不要用欧美绿涨红跌)。
- 大数字用主色或强调色,单位小字号跟在数字后;百分比保留 1 位小数要全稿统一。
- 图表配色从当页模板取色,不引入第三套色;图例能省则省,数据标签直接标。

## 4. 页面解剖(全库统计结构)

一套完整汇报的页型序列(**缺页即缺节奏**):

```
封面 → 目录 → [过渡页 → 内容页 × 3–6] × N 章 → 结尾页
```

| 页型 | 识别特征 | 内容构成 | 占比(实测) |
|---|---|---|---|
| 封面 | 第 1 页;主标 66–115 pt | 主标 + 副标(场合一句话)+ 汇报人/部门 + 日期 | 1 页 |
| 目录 | 含"目录/CONTENTS" | 3–5 条,编号(一/二/三/四 或 01–04)+ 每条 ≤10 字 | 1 页 |
| 过渡页 | 文本 ≤4 条;大编号 + 章节名 | 章节号(大)+ 章节标题 + 英文小字注释 | 每章 1 页 |
| 内容页 | 主体;文本多 | 页标题(结论句)+ 一种主体构图 | 全套的 50–70% |
| 数据页 | 含大数字/百分比/图表词 | 1 个核心数字 + 2–4 个支撑指标,或一张图 | 每章 1–2 页 |
| 结尾页 | 含 THANKS/谢谢/感谢 | 致谢语(≤12 字)+ 汇报人 + 日期 | 1 页 |

- 过渡页是这套库的灵魂节奏器:**章与章之间必须插过渡页**,否则内容页连排会喘不过气。
- 版权页/论坛宣传页(如 084-p26 的"锐普论坛"页)**不是结尾页,弃用**。

## 5. 内容页构图词表(锐普系模板的关系图语言)

84/086 等锐普系模板把内容页构图做成了"关系图词典",选构图=选逻辑:

| 构图 | 语义 | 典型形态 |
|---|---|---|
| 并列关系 | 对象间平等,无先后 | 2–6 个等宽卡片/方块横排或竖排 |
| 层级关系 | 层次性差异 | 金字塔/阶梯/大小块分层 |
| 递进关系 | 发展阶段脉络 | 箭头链,由弱到强/由浅到深 |
| 扩散关系 | 一个结论分解为几部分 | 中心向四周发散 |
| 聚合关系 | 几个部分汇成一个结论 | 多路汇入中心 |
| 包含关系 | 整体与部分 | 大形状套小形状 |
| 组织关系 | 架构/分工 | 树状/矩阵 |
| 联动关系 | 对象间紧密联系 | 双环/齿轮/对接 |
| 循环关系 | 循环变化 | 圆环/循环箭头 |
| 流程关系 | 操作先后顺序 | 横向流程带 |
| 数据页 | 量化证据 | 大数字 + 百分比 + 圆环/条形/扇形图 |
| 图文页 | 场景佐证 | 大图 + 一侧文字 |

## 6. 从零搭页的兜底规则(没有合适模板时)

1. 画布 33.9 × 19.1 cm;页标题左上 32 pt 微软雅黑加粗,下方 0.2 cm 粗短线(主色,长 2.6 cm)。
2. 内容区按 12 列网格排卡片;卡片 = 圆角矩形(白底/深色底)+ 1 pt 主色顶边或左侧竖条。
3. 卡片标题 20 pt,正文 14 pt,行距 1.2;一张卡片不超过 4 行。
4. 强调色只点在"当前要观众看的那一个"上。
5. 页脚:细线 + 8 pt 灰色页码/口径,不压内容。
6. 自检:把页面缩略到 25% 看,构图重心、留白、强调点仍成立才算过。
