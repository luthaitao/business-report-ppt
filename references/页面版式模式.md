# 页面版式模式:donor 选型、outline 写法与替换纪律

> 本文管"装配"环节:怎么从模板里挑捐赠页(donor)、怎么写 outline、替换时守什么纪律、交付前查什么。
> 引擎命令细节见 `SKILL.md`;槽位 id 的含义以 `build_deck.py analyze` 输出为准。

## 1. donor 选型:按页型去模板里"认页"

对候选模板先跑 `analyze`,按 `type` 字段认页:

| 页型 | analyze 的 type | 认页特征(辅助判断) |
|---|---|---|
| 封面 | `cover_or_section`(第 1 页) | 含超大字号文本(66–115 pt) |
| 目录 | `toc` | 文本含"目录/CONTENTS" |
| 过渡页 | `cover_or_section`(非第 1 页) | 文本 ≤4 条,常带大编号+英文小字 |
| 内容页 | `content` | 文本多,有"添加文本/单击此处添加标题"占位 |
| 数据页 | `content` | 槽位文本是纯数字/百分比,或含"图"字标题 |
| 结尾页 | `end` | 含 THANKS/谢谢/感谢 |
| 弃用页 | — | 版权/论坛宣传/联系方式/素材说明页(**永不做 donor**) |

- 一套模板通常有 1 封面 + 1 目录 + 若干过渡 + 十几页内容 + 1 结尾,**内容页可重复用**(同一 donor 出现多次,引擎每次独立深拷贝)。
- 内容页要**轮换构图**:相邻两页不用同一种关系图;数据章至少 1 页大数字页;每章第 1 页用过渡页隔开。
- 拿不准某页是什么,直接导出该模板预览(`export_preview.py` 对原模板跑一遍)看图,比读 JSON 快。

## 2. outline 写法

```json
{
  "pages": [
    {"donor": 1, "drop": ["1:3"], "fit": true,
     "slots": {"1:1": "季度汇报", "1:2": "2026年第三季度经营分析",
               "1:4": "汇报人：张明\n日期：2026年10月", "1:5": ""}},
    {"donor": 3, "slots": {"3:10/5": "经营回顾", "3:11/5": "问题与风险"}},
    {"donor": 5, "slots": {"5:0": "经营亮点", "5:7/2": "营收增长", "5:7/3": "同比增长18%"}}
  ]
}
```

- `donor`:模板原始页码(1 起);`pages` 数组顺序 = 输出页序。
- `slots`:`{槽位id: 新文本}`;多行文本用 `\n` 分段(自动沿用首段格式)。
- `drop`:[槽位id...] 删除形状——**模板自带 logo/水印/版权图形必删**(logo 在右上角 x≈29–31 cm,是无字组合形状,analyze 的 pics 列表里没有它,按位置+组合特征判断)。
- `fit`:true 时,该页替换文本明显变长就按比例缩字号(下限 0.6 倍)。**兜底不是万能**,大字号槽位仍要控字数。
- 想清空某个槽位,置 `""` 即可(保留形状、去掉文字)。

## 3. 替换纪律(违反必返工)

1. **字数对齐**:新文本字符数 ≈ 原文本。拉丁字符按 1、汉字按 2 折算(如原 "POWERPOINT" = 10,中文主标最多 5 字)。
2. **大字号槽位收紧**:≥60 pt 的槽位,中文 ≤4 字;≥100 pt 的槽位,中文 ≤3 字。放不下就改短,别指望缩字号。
3. **目录条目 ≤10 字/条**,3–5 条;章节标题 ≤12 字;正文单行 ≤30 字,一段 ≤4 行。
4. **多行结构对齐**:原槽位是 4 行手动换行的说明文字,替换时也给 4 行以内的文本;原槽位单行就别塞长句。
5. **不改设计**:不手调位置/颜色/字号去"适配"内容——改 outline 重跑。fit 只允许引擎自动缩字号。
6. **数字带口径**:业绩数字注明周期与口径(如"同比增长18%(2026Q3 vs 2025Q3)");不确定的一律写"待补"并在交付前清零。

## 4. 交付前校验清单

`build_deck.py verify` 之外,导出预览后逐页看图,查:

- [ ] 无占位残留(点击/单击/添加/XXXX/XX月XX日/Click here/Welcome to use)
- [ ] 无模板品牌元素(logo 组合、版权页、论坛/商城地址、设计师署名)
- [ ] 文字无溢出裁切(尤其封面主标、卡片标题;汉字比拉丁宽一倍)
- [ ] 目录条目与实际章节一一对应
- [ ] 相邻页构图不重复;每章有过渡页
- [ ] 正文 ≥12 pt;一页一个强调色
- [ ] 数据口径齐全;"待补"清零
- [ ] 4:3 模板(023/051/061/074/079)没被误用到 16:9 场合(反之亦然)

## 5. 常见问题

| 症状 | 原因 | 解法 |
|---|---|---|
| 封面主标被裁掉半个字 | 汉字宽度 ≈ 拉丁 2 倍,超出槽位 | 主标压到 3–4 字,或换主标槽位字号更小的模板 |
| 目录剩一两条空着 | outline 没填满该 donor 的全部条目槽 | 补 slots,或换条目数匹配的 donor |
| 某页文字变成默认宋体 | 该槽位原本无 run(空文本框架) | 换有文本的 donor;或接受默认格式后手动在 PowerPoint 里统一字体 |
| 图片/背景不见了 | donor 的图形在母版里,而构建用了错误版式 | 引擎按 donor 的 layout 建页,正常不会丢;若丢失,换 OOXML 模板重试 |
| 旧 .ppt 打不开 | python-pptx 只认 OOXML | 先另存为 .pptx,或换同族 OOXML 模板(见 模板索引.md) |
